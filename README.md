🔧 FireGraph – Visual Scripting Tool for Custom Logic in Unity
FireGraph is a lightweight and extensible node-based visual scripting tool designed for Unity. It allows developers to build and execute custom logic using a graph editor, variable blackboard, and dynamic nodes.

Whether you're prototyping game mechanics, setting up quest logic, or building custom editors, FireGraph gives you full control and flexibility over your logic, directly in the Unity Editor.

✨ Features
🧩 Node-based system with custom nodes and ports

📦 Modular architecture, easy to extend

🎛 Integrated variable blackboard with type support and value editing

🔄 Support for runtime execution and editor preview

💾 Fully serializable with ScriptableObject asset storage

🧠 Ideal for logic prototyping, AI behaviours, dialogue trees, and more

✅ Use cases
Custom gameplay logic

Dialogue and branching systems

Procedural generation setups

Quest / objective chains

AI behaviour graphs
